## Parameterized and accessibility copy

Use String Catalog plural variants for counts; retain the same named arguments
in both languages. Dates, numbers and ordering follow the active locale.

| Purpose | English (en) | Vietnamese (vi) |
|---|---|---|
| Position | Photo {position} of {total} | Ảnh {position} trên {total} |
| Source count | {count} photos selected | Đã chọn {count} ảnh |
| Analysis count | {completed} of {total} photos analyzed | Đã phân tích {completed} trên {total} ảnh |
| Confirmation count | Delete {count} original photos | Xóa {count} ảnh gốc |
| Proposed per-photo change | {dimension}: {oldValue} → {newValue} | {dimension}: {oldValue} → {newValue} |
| Album dimension | Album membership | Trạng thái trong album |
| Cleanup dimension | Cleanup choice | Lựa chọn dọn dẹp |
| Album unset / included / excluded | Not chosen for album / In album / Excluded from album | Chưa chọn cho album / Có trong album / Không đưa vào album |
| Cleanup undecided / keep / staged | Undecided / Keep / Staged for deletion | Chưa quyết định / Giữ lại / Trong danh sách xóa |
| Advisory suggestion | Suggestion available | Có đề xuất |
| No suggestion | No suggestion | Không có đề xuất |
| Available action | Action: {action} | Thao tác: {action} |

Compose photo VoiceOver labels from position, album state, cleanup state,
review progress, analysis/suggestion availability, and named available actions.
Use the same localized state names in proposal previews. The generic saved-choice
message is valid only after successful persistence; it is not a save-error fallback.

Copy rules: say **Remove from Album** for membership, never use an album
exclusion label to imply library deletion; say **Stage for Deletion** only for
the reversible cleanup disposition; and always pair deletion confirmation with
the full-access and iCloud/Recently Deleted disclosure when applicable.

Accessibility labels must include the photo position, the independent album
and cleanup states, and the available action. Color and icons never carry a
state alone. All strings ship in English and Vietnamese; no new feature may
use an untranslated fallback string.
