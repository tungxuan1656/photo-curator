## Parameterized and accessibility copy

| Purpose | English | Vietnamese |
|---|---|---|
| Position | Photo {position} of {total} | Ảnh {position} trên {total} |
| Query total | {count} matching photos | {count} ảnh phù hợp |
| Selection | {count} photos selected | Đã chọn {count} ảnh |
| Select all scope | Select All {count} Matching Photos | Chọn tất cả {count} ảnh phù hợp |
| Group coverage | {matched} of {total} photos match your filters | {matched} trên {total} ảnh phù hợp với bộ lọc |
| Analysis coverage | {completed} of {total} accessible photos analyzed | Đã phân tích {completed} trên {total} ảnh có thể truy cập |
| Delete confirmation | Delete {count} original photos | Xóa {count} ảnh gốc |
| Availability | {pending} pending · {unavailable} unavailable | {pending} ảnh đang chờ · {unavailable} ảnh chưa có kết quả |

Use String Catalog plural variants and identical argument names in both languages.
VoiceOver labels compose position, action-selection state, relevant labels, and named actions.
Group controls expose relation and count. Color never carries the only state signal.
Never translate raw provider identifiers as user labels without taxonomy mapping.
Retain legacy catalog strings while compatibility screens still reference them.
